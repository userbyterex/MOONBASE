# MOONBASE (LUNA) — Beta 2.0

OGame-style lunar empire builder.

## Features
- Buildings upgrade by **level** (not multiple copies)
- Continuous resource production (Regolith, Ice, Helium-3)
- Energy system (mines slow down if energy is low)
- Construction queue (one upgrade at a time)
- Robotics Factory reduces build time
- Factions with permanent bonuses
- Moon claim + Planetary Governors
- Offline production catch-up
- Surface view + Overview + Buildings tabs

## How to play
1. Choose faction → Launch → Claim a moon
2. Upgrade Regolith Mine, Ice Extractor, Solar Plant
3. Keep Energy positive
4. Expand Dome, Habitat, O2, Hydroponics
5. Build Robotics → Shipyard (fleet next version)

Start a **new colony** (old saves use different key).
