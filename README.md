# MOONBASE (LUNA)

Lunar colony simulation — mine resources, grow your population, claim moons and become Planetary Governor.

## Beta 1.0

- Choose your **Faction** (TerraCorp, Aether Guild, Red Legion, Gaia Collective, Void Syndicate)
- Launch rockets from Earth (free in this beta — token burn coming later)
- Claim limited moons in Earth orbit
- Build your base: Dome, Oxygen Generator, Hydroponics, Habitats, Mining Rigs, Power
- Resource production + population + morale system
- Planetary Governors (majority of moons = control of the planet)
- Auto-save (localStorage)

## How to Play

1. Open `index.html` in any modern browser (or enable GitHub Pages).
2. Select a faction → Launch rocket → Claim a free moon → Build & survive.
