# MOONBASE (LUNA)

Lunar colony simulation — choose a faction, launch your rocket, claim moons and become Planetary Governor.

## Beta 1.1

- 5 unique factions with character avatars
- Professional rocket launch animation sequence
- Claim limited moons in Earth orbit
- Build base: Dome, Oxygen, Hydroponics, Habitats, Mines, Power
- Resource production + population + morale
- Planetary Governors system
- Auto-save

## How to Play

1. Open the site (GitHub Pages) or `index.html`
2. Select a faction → Choose moon → Watch the launch → Build & survive
